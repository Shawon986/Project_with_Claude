To run the website into your browser please follow the command below :

To run the Website with backend :

    python -m uvicorn web.backend.app:app --reload --host 127.0.0.1 --port 8000


To run the Website with frontend :-
    Command : npm run dev (You have to run it after changing the path to C:\Users\shawo\hangzhou-housing-analysis\web\frontend inside your terminal)
